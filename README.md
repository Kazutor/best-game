EMBERDRIFT is a neon arena survival shooter, written from scratch: drift through a glowing arena, blast waves of enemies, grab upgrades between rounds, and survive as long as you can. It runs in a desktop browser from static files with no network request, played with keyboard and mouse, complete from its start screen to its game-over restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
